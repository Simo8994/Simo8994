# Officina

Pianificazione settimanale di commesse e attività. Stato: versione minima con dati finti in memoria.

```bash
npm install
npm run dev          # http://localhost:3000
npm run tokens       # rigenera i token da replica/design/tokens.json
npm run build && npm start
```

Utenti di prova: `anna.rossi` (admin), `luca.bianchi`, `giulia.verdi`, `paolo.neri`; password `demo`.
I dati si azzerano a ogni riavvio. In produzione impostare `SESSION_SECRET`.
