# Fonti e query di ricerca

Usa la ricerca web in modalità "standard" per gli scan rapidi; passa a "extended" per nicchie, mercato italiano o quando i risultati sono pochi o vecchi. Lancia più ricerche indipendenti nello stesso turno.

Sostituisci `{app}`, `{settore}`, `{attività}` con i valori reali.

## Store di app

| Fonte | Query / metodo | Note |
|---|---|---|
| App Store | `site:apps.apple.com {app}` per trovare la scheda; leggi le recensioni dalla pagina | Le recensioni visibili sono poche; cerca anche su siti aggregatori di recensioni |
| Google Play | `site:play.google.com {app}` | Ordina mentalmente per recenti/negative; nota la risposta dello sviluppatore |

## Directory software B2B

| Fonte | Query |
|---|---|
| G2 | `site:g2.com {app} reviews`, `site:g2.com {app} alternatives` |
| Capterra | `site:capterra.com {app}`, `site:capterra.it {app}` |
| GetApp / Software Advice | `site:getapp.com {app}` |
| Trustpilot | `site:trustpilot.com {app}` |

Su G2 e Capterra i campi "Cons" / "Contro" sono già le lamentele: usali.

## Community

| Fonte | Query |
|---|---|
| Reddit | `site:reddit.com {app} (hate OR sucks OR alternative OR "switched from")`, `site:reddit.com "{attività}" software recommendation` |
| Reddit Italia | `site:reddit.com/r/italy OR site:reddit.com/r/ItaliaPersonalFinance {settore} programma`, subreddit di settore |
| Hacker News | `site:news.ycombinator.com {app}` |
| Forum italiani | `"{settore}" forum programma gestionale`, `"{attività}" "che programma usate"` |
| Gruppi Facebook / LinkedIn | spesso non indicizzati: segnalalo e suggerisci all'utente di cercare lì a mano |

## Segnali di domanda

| Segnale | Query |
|---|---|
| Ricerca di alternative | `"alternativa a {app}"`, `"{app} alternative"`, `"{app} too expensive"`, `"{app} costa troppo"` |
| Bisogno senza soluzione | `"programma per {attività}"`, `"app per {attività}"`, `"come gestire {attività}" excel` |
| Workaround | `"{attività}" excel template`, `"{attività}" whatsapp gestione` |
| Prezzi | pagina prezzi ufficiale di ogni concorrente; annota data |
| Normative | `{settore} obbligo {anno} software`, `{settore} nuova normativa digitale` |
| Crescita concorrenti | `{app} funding`, `{app} raises`, `{app} price increase` |
| Lavoro manuale pagato | annunci per "addetto prenotazioni", "segreteria" ecc. nel settore |
| Bacheca richieste del prodotto | `{app} feature request`, `{app} roadmap`, `{app} canny` |

## Dati sul settore (per dimensionare)

Usa solo fonti citabili: ISTAT, Camere di Commercio / Infocamere, associazioni di categoria, report pubblici. Se manca il dato, fai una stima esplicita (es. "N attività × % che usa software × prezzo medio") e marcala come stima.
